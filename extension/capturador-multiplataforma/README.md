# Capturador Multiplataforma v1.1.1

## Instalação
1. Baixe o ZIP da branch e extraia-o.
2. Abra chrome://extensions, habilite Modo do desenvolvedor e clique Carregar sem compactação.
3. Escolha esta pasta, que contém manifest.json.

## Envio
Configure a URL HTTPS exata do endpoint e, apenas se oficialmente suportado, um token de integração. Revise o preço, imagem e link de afiliado HTTPS e clique Enviar oferta ao Radar. O resultado HTTP é mostrado e salvo no histórico local.

**Importante:** endpoint, esquema do payload, autenticação e CORS devem ser confirmados no backend implantado. Não cole senha nem cookies. HTTP 2xx não prova sozinho que o item foi persistido; confira o catálogo.
