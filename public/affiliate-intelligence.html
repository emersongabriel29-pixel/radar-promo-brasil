Critério de prioridade: média de estrelas 55%, vendas 30% e crescimento 7d 15%, considerando apenas os sinais disponíveis. Loja oficial Shopee Mall recebe valorização adicional e desempata produtos com a mesma nota. A API usada não fornece quantidade de avaliações; por isso, não calculamos nota ponderada por número de reviews e nunca usamos vendas como substituto. Ofertas com nota menor continuam elegíveis. Crescimento só é exibido quando existem observações separadas por pelo menos sete dias. Dados ausentes não são estimados.

Radar de concorrência Shopee Vídeos

O Radar cruza vendas, avaliação, comissão e preço da API oficial com uma amostra de concorrência que você registra manualmente. Não há coleta automática na Shopee Vídeos: os termos da plataforma restringem robôs e scripts de coleta. Use sempre o mesmo tamanho de amostra para comparar produtos.

\n

Analise sempre a mesma quantidade de resultados (por exemplo, os primeiros 30) para comparar produtos de forma justa. Conte criadores únicos, não aparições repetidas.
